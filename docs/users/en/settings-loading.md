# Loading Settings translations

Settings loads its English and French feature text only when opened. A translated loading message appears before its controls; shared labels and the language selector remain available.

If that download fails, Settings shows an error instead of partially translated controls. You can **Close** it and return to chat. An ongoing detached run remains stoppable there.

**Reload and retry** reloads the page to retry the failed module. Review unsent text before reloading. Simply reopening Settings does not clear the failed import. Changing sessions or workspaces while loading does not let a late download reopen the old view.

This changes text delivery, not provider credentials, project trust, saved configuration or session history. It does not add a third supported language.

See the [user guide](./user-guide.md) and [resource group controls](./resource-batches.md).
