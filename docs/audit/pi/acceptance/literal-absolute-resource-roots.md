## Boundary and semantics

The public string helper is not changed or replaced with escaped pseudo-paths. `ResourceManager` associates an absolute legacy string only with its **longest already configured literal cwd/agent/home root**. Relative strings retain their former cwd resolution. No filesystem probe guesses a declaring directory; callers must supply the same roots used for settings resolution. For arbitrary additional literal identities, use an explicit scoped record or exact `+`.

The shared internal `relativeResourceSelector` makes an absolute selector **inside its already literal base** relative before locating pattern metacharacters. Markdown uses the same operation for glob detection/search roots/matching; extension/theme discovery uses it before normalization. This prevents the base's `[literal]`, `?`, `*` or brace characters from authorizing sibling matches. The rest of the pattern remains a pattern: nested directory classes and outside-base absolute globs are deliberately not converted to literal paths. Absolute directory requests retain recursion and trailing-directory intent.

Exclusions still only reduce admitted metadata and do not read excluded bodies. Stable descriptors, nonsymlink/single-link files, file/scan/depth/count limits, fresh project trust, exact package paths, scoped snapshots, ordering and discovery/all-loading distinctions remain authoritative. No new Core root export, SDK major, persisted/session/wire schema, dependency/lockfile, Server/Web product or golden change belongs to this delivery.
