# MCP-01 — Native configuration, Test, OAuth and hosting

This is the native delivery contract for [AUDIT-5](AUDIT-5.md), not a Pi file/CLI/SDK compatibility promise. The approved independent-product and direct-default decisions remain authoritative. MCP resources, extension registration and exhaustive exposure qualification belong to MCP-03, MCP-04 and MCP-02 respectively.

## Configuration map

Global configuration is `<agent-dir>/mcp.json`; trusted project configuration is `<cwd>/.ai-harness/mcp.json`. Files remain bounded regular nonlinked JSON/JSONC. An exact saved allow is not required when a fresh inherited persisted allow applies; a nearer refusal always wins. A targetless project entry may override only `enabled`, `exposure`, `toolExposure`; complete targets replace the global entry. No credential or target is copied into a control-only project override.

| Pinned Pi field/workflow | Native contract |
|---|---|
| `mcpServers`, optional transport `type` | Same container; optional native `version: 1`. `command` selects stdio; `url` selects Streamable HTTP. Explicit `stdio`, `http`, `streamable-http` must agree. Legacy SSE is refused. Invalid entries do not authorize a connection. |
| `command`, `args`, `cwd` | One executable plus literal argv, never a shell command string. Relative cwd resolves through allowed-root and fresh project trust checks. Use absolute paths rather than relying on Pi's home expansion in argv. |
| `env`, `headers` | Bounded string maps; native `${NAME}`/`$NAME` and whole-value `!command` resolution only at an explicit Test/login or eligible runtime connection. Reserved host authentication/master-key variables cannot be delegated. Child environments are filtered. |
| `description` | Bounded descriptive metadata; remote instructions do not become execution authority or arbitrary system instructions. |
| `timeout` | Positive finite seconds, at most 300; reduces the owning host's per-request ceiling, never expands it. Existing whole-Test/startup/OAuth/close deadlines remain authoritative; progress cannot extend the absolute ceiling. Missing values preserve native defaults (15 seconds/request for Test and hosting). |
| `enabled`, `exposure`, `toolExposure` | Existing native controls, direct default and exact-before-ordered-star matching unchanged. No migration to Pi's codemode default. |
| `oauth.clientId`, `clientSecret` | Pre-registered client; secret may be a native variable or whole-value command, resolved only after a challenge. No Authorization-header server is OAuth-managed. |
| `oauth.scope` / native `scopes` | Space-separated fallback or bounded string array; direct files reject simultaneous forms. Paste conversion normalizes to `scopes`. Advertised/challenged scopes remain SDK-owned. |
| `oauth.clientName` | Explicit dynamic-registration name, default `AiHarness`; changing it does not silently re-register an existing client. Sign out before registering again. |
| `oauth.callbackPort`, `callbackUrl` | Explicit loopback HTTP callback on `localhost`, `127.0.0.1` or `[::1]`; no credentials/query/fragment. Default path `/oauth/callback`. Custom paths and ephemeral ports are supported. Conflicting ports fail validation; an occupied explicitly configured port fails rather than changing a registered URI. Only obsolete stored dynamic registrations may fall back to an ephemeral port. URLs use native URL canonicalization. |
| `oauth.authServerMetadataUrl` | Explicit HTTPS (or loopback HTTP) metadata override without credentials/query/fragment, loaded only after a challenge through bounded fetch and fresh validation. The operator trusts the configured document. Standard discovery rejects issuer mismatch before registration. No global fetch replacement. |
| `oauth.clientRegistration: "cimd"` | Require an operator-owned HTTPS, non-root `clientMetadataUrl` without credentials/query/fragment; never impersonate Pi using its pi.dev document. Refuse conflicting client ID/secret/name, unsupported issuer CIMD/public-client capabilities, and silent fallback to DCR. A registration-mode/client-ID change cannot send the previous client's Bearer before discovery or reuse CIMD credentials as a dynamic client. |
| Pi plaintext `mcp-auth.json` | No import or plaintext writer. Name plus normalized URL owns an opaque encrypted record in native `credentials.enc`; same name/URL across scopes shares sign-in, different names isolate accounts. The additive `cimd` client-mode discriminator preserves older dynamic/configured records. |
| `autoEnableCodemode`, foreign `auth`, Pi extension replacement | Not native file authorities. Use native tool/settings/builtin-extension policy; foreign paste conversion is explicit. Unknown file properties produce value-free diagnostics. |

## Management and lifetimes

- `ai-harness mcp list|status` and interactive `/mcp` are **passive**, unlike Pi's shell list that connects. Use explicit `test <name>` for bounded connectivity. A failed **or needs-auth** Test exits nonzero; no tool is called, no OAuth registration starts and no credential is written.
- `add <name> --url <url>` and `add <name> -- <executable> [argv...]` retain their existing grammar. `add <name> --config '<native-entry-json>'` passes the complete entry through the same bounded paste/reparse writer as Web. Literal global secrets require `--confirm-literal-secrets`; transmitted host variables require name-bound `--confirm-remote-variable NAME`. Project secret/trust restrictions remain mandatory.
- Shell `enable`, `disable`, `exposure`, `remove`, `login`, `logout`, and the same explicit `/mcp` actions reuse Core. Both terminal renderers support them without a model request. Interactive actions retire same-name process-local connections across both scopes, including inherited targets/shared OAuth identities; unchanged prompts retain their connections. `/mcp tools|reconnect` and `/reload` keep existing lazy fresh preparation. An extension-owned `/mcp` retains precedence. Échap cancels owned Test/login/tool preparation through the command's abort signal without stopping the editor.
- Interactive login publishes the authorization URL immediately and uses the browser callback without stealing the editor's stdin. Standalone shell login also supports bounded redirected-URL paste. Web independently owns explicit start/poll/paste/cancel/logout; tokens/verifiers never cross its DTO boundary.
- Ordinary CLI/RPC/Web connections may use or refresh stored state but may not display authorization, register an interactive client or resolve a secret before challenge. OAuth validates exact config/trust before resolution, network continuation, verification and every credential write. CAS snapshots plus durable sign-out markers reject stale/cross-process refresh writers.
- Persistent connections survive unchanged prompts, reconnect after disconnect on the next prompt, and close on disable/replacement, session release, idle expiry or bounded shutdown. Stop retires unpublished startup/discovery. Changed-tool notifications refresh future declarations and withdraw unsafe prepared bindings. Tool calls are not automatically retried after possible side effects.
- The explicit high-level session SDK still does not auto-discover MCP/auth. Low-level Core hosting remains available; no new AgentSession facade authority is added.

## Qualification limits

No vendor account, Pi process, foreign-file migration, physical-terminal/browser-platform matrix or remote revocation is certified. Operators own network endpoints, commands and CIMD metadata publication. Native credentials stay encrypted and passive reads stay passive. Historical failures in AUDIT-5 are not repaired by a later passing scoped run; whole-platform QUA-01 remains independent. MCP-02/03/04 are not closed by this delivery.
