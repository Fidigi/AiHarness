# MOD-02 — Native selection, discovery and transport

> Authority: [AUDIT-5 §§2–3](./AUDIT-5.md#3-traceability-by-surface). This is a requirement/evidence map, not a second backlog or complete provider-parity certificate.

## Scope

The independent native product decision in AUDIT-5 §5 keeps AiHarness configuration, credentials and public interfaces authoritative. MOD-02 verifies selection and transport for admitted adapters; the complete pinned provider catalogue, authentication and live-account matrix remain MOD-01. Model-specific reasoning, replay and budgets remain MOD-03.

Native endpoint configuration uses Core/CLI trusted provider registration and Server custom-provider/model administration. It does not automatically read Pi `models.json`, import credentials or overlay foreign cache files. No new persistence format or file-loading authority is added.
